# 测试木桩 DPR 工具

重返未来：1999 手动战斗模拟与木桩 DPR 计算器。项目为单个 HTML 页面加本地数据脚本，无需安装依赖或构建，适合用来手动模拟回合、验证技能机制和计算队伍 DPR。

## 功能

- 四位角色：虚构集、莫莉德尔、小瑞安侬、J
- 角色配置：心相、塑造、共鸣预设 / 自定义共鸣、共鸣调频
- 木桩配置：现实 / 精神防御、抗爆率、暴击防御、受创减免、克制系数、灵感
- 调律系统：未尽的调律、最初的刻度
- 手牌操作：打出、移动、相邻自动合成、预备咒语、至终的仪式
- 特殊机制：木桩回合末攻击、莫莉德尔反击、J 高温回火、虚构集筹备、小瑞安侬使役通感
- 本回合内撤回上一步操作
- 伤害日志、总伤 / 回合伤 / 平均 DPR 统计

## 快速开始

### 方式一：直接打开

双击打开 `木桩测试.html` 即可使用。

### 方式二：本地服务器（推荐）

部分浏览器会限制本地文件加载同目录脚本，推荐用本地 HTTP 服务器打开：

```bash
cd 木桩DPR
python -m http.server 8765
```

然后访问：

```text
http://localhost:8765/木桩测试.html
```

### 方式三：单文件版

直接下载并双击 `测试版v1.html` 即可使用，无需安装依赖或启动服务器。单文件版已把 `data/` 数据全部内联。

## 使用说明

### 1. 配置角色

在左侧展开角色配置面板：

- 心相：选择该角色携带的心相
- 塑造：选择 0-5 塑造档位，页面会显示对应效果描述
- 共鸣：选择共鸣 10 预设、共鸣 15 预设或自定义
- 共鸣调频：在角色面板中切换，影响共鸣属性分配
- 自定义共鸣：手动填写攻击、生命、防御、暴击、创伤、威力、穿透等属性

### 2. 配置木桩

在“木桩配置”中修改防御、抗爆率、暴击防御、受创减免、克制系数和灵感，点击“应用”生效。

克制关系：星 → 岩 → 兽 → 木 → 星；灵 ↔ 智 互克。

### 3. 调律

选择“未尽的调律”或“最初的刻度”，使用调律技能生成或替换手牌。切换调律会重新开始战斗，但保留角色与木桩配置。

- 最初的刻度：技能 1 每回合 1 次；技能 2 不限制次数
- 未尽的调律：技能 1、技能 2 每回合各 1 次
- 使用次数会在每回合开始时重置

### 4. 战斗操作

- 点击手牌上的“打出”使用技能；预备咒语不消耗行动点
- 点击“移动”后选择目标位置，相邻同角色、同技能、同阶卡牌会自动合成
- 回合中激情满不立即发大招；发牌时优先发放至终的仪式，并占用普通手牌位
- “撤回上一步”可逐步撤销本回合内的打出、移动、合成、调律技能和使役通感
- “结束回合”结算燃烧、木桩攻击、反击与状态持续时间，然后进入下一回合
- “重置战斗”只清空战斗状态，保留角色和木桩配置

撤回历史会在结束回合、重置战斗、切换调律或修改配置时清空。

## 伤害计算

最终伤害 = 倍率项 × 攻防项 × 创伤项 × 暴创项 × 威力项 × 克制项 × 最终项

- 倍率项：技能 / 咒语 / 大招自带倍率
- 攻防项：进战攻击 × 攻击增减 - 进战防御 × 防御增减 ×（1 - 穿透率），保底当前攻击力的 10%
- 创伤项：1 + 我方创伤加成总和 - 敌方受创减免总和，保底 0.3
- 暴创项：暴击时为我方暴击创伤 - 敌方暴击防御，保底 1；非暴击为 1
- 威力项：1 + 术法威力 / 仪式威力 / 术具威力提升，保底 0
- 克制项：1 + 0.3 + 其他克制系数来源
- 最终项：1 + 最终增伤 - 最终免伤

## 已知说明

- 有专属名字的队伍 buff（如“战备部署”“群鸟之歌”“昨日雨声轻”“家庭指导员”“加护”）独立叠加、独立计时
- 通用同名 buff（如“创伤加成提高”“受创减免提高”“反击创伤加成提高”）按数值高者覆盖，不叠加
- J 狂想Ⅳ下【高温回火】不再按已损生命增伤，改为每层燃烧按原损血增伤的 50% 加伤，并额外造成 900% 基础现实创伤
- 本工具仅做手动模拟，不替代游戏内实际数值验证
